Q1 · centre↺ day 1

Which centre survives a typo?

x = [2, 3, 3, 8, 50]

Find the mean, median and mode. Then the 50 is mistyped as 500. Which ones move?

sim drag the outliermean · median · mode
mean13.2
median3
mode3

Mean 13.2, median 3, mode 3. With 500, the mean jumps to 103.2; the median and mode don't move. One bad value drags the mean as far as it likes, because the mean is a balance point and the median is a middle rank.

Q2 · variance↺ day 2

Divide by n or by n − 1?

x = [4, 7, 9, 10, 15]

Compute the variance with ddof = 0 and ddof = 1.

mean = 9 · squared deviations = 25 + 4 + 0 + 1 + 36 = 66

ddof = 0: 66 / 5 = 13.2 (the population formula). ddof = 1: 66 / 4 = 16.5 (a sample estimate). Deviations are measured from the sample's own mean, which sits closer to the data than the true mean, so dividing by n underestimates. n − 1 corrects that.

Q3 · percentiles & fences↺ day 2

Is 55 an outlier?

x = [3, 8, 10, 14, 21, 30, 55]

Find Q1, the median and Q3 with h = (n − 1)q (0-based, linear interpolation), then Tukey's fences.

Q1: h = 6 × 0.25 = 1.5 → 8 + 0.5 × (10 − 8) = 9   median = 14   Q3: h = 4.5 → 21 + 0.5 × 9 = 25.5
IQR = 16.5   fences = 9 − 24.75 = −15.75 · 25.5 + 24.75 = 50.25   55 > 50.25 → outlier
Q4 · masking↺ day 2

Can a z-score rule even fire?

With only n = 5 values, what's the largest |z| any point can have? And how big must n be before "|z| > 3" can flag anything at all?

sim the most extreme dataset possiblezscore_outliers(x, t=3.0)
max |z| = (n−1)/√n1.789
can |z| > 3 fire?no
the worst case: n − 1 identical values and one huge outlier. The outlier inflates the very std it's measured with, so it can't look extreme. That's masking.

At n = 5, max |z| = 4/√5 ≈ 1.789. A "|z| > 3" rule can never fire. The first n where it can is 11 (n = 10 gives 2.846; n = 11 gives 3.015). On small samples, use Tukey's fences instead.

Q5 · scaling↺ day 3

Stretch the data: who notices?

cov = 6, sₓ = 2, s_y = 5

Find r. Then transform y′ = −3y + 10. What happens to cov and r? And what if x is converted from metres to centimetres?

sim scaling playgroundcovariance(x, y) · pearson(x, y)
cov(x, y′)6
r0.6
s_y′5
cov stretches by a and doesn't care about b. r only notices the sign of a: it's covariance divided by both spreads, so units cancel.
r = 6 / (2 × 5) = 0.6   cov(ax, by) = ab·cov

y′ = −3y + 10: cov = −3 × 6 = −18, r = −0.6. Metres → cm multiplies x by 100: cov = 600, r stays 0.6.

Q6 · ranks↺ day 3

Ties, and an outlier that doesn't matter

rank([7, 3, 7, 1, 7]) = ?

Then compare Pearson and Spearman for x = [1, 2, 3, 4, 5], y = [1, 2, 3, 4, 100].

Ranks: [4, 2, 4, 1, 4]. The three 7s share positions 3, 4 and 5, so each gets their average, 4. For the pair, Spearman = 1.0 (perfectly monotonic) while Pearson ≈ 0.725 (the 100 bends the straight-line fit). Spearman is just Pearson on ranks, so the outlier becomes "rank 5" and stops shouting.

Q7 · causation↺ day 3

RLHF causes sycophancy?

Across 6 models, the amount of RLHF and a sycophancy score correlate at r = 0.8. Does RLHF cause sycophancy? What else could explain it, and how would you test it?

Confounder: model scale. Bigger models get more RLHF and may be more sycophantic for other reasons. Reverse direction: labs may apply more RLHF to models that already flatter users. Test: randomly assign RLHF vs a control to otherwise identical models, then compare. Six models is also a tiny sample.

Q8 · independence↺ day 4

Does the first die tell you anything?

Two dice. Is "sum = 7" independent of "first die = 3"? What about "sum = 8"?

P(sum 7) = 6/36 = 1/6, and P(sum 7 | first = 3) = 1/6. Equal, so independent: whatever the first die shows, exactly one face of the second makes 7. P(sum 8) = 5/36, but P(sum 8 | first = 3) = 1/6. Not equal, so not independent: a first die of 1 makes 8 impossible.

Q9 · bayes↺ day 5

The sycophancy judge

10% of model responses are truly sycophantic. A judge flags 90% of those, but also flags 15% of normal responses. If a response is flagged, how likely is it really sycophantic? And what does the flag rate say about the true rate?

sim 1,000 responsesbayes_posterior(prior, p_flag_given_yes, p_flag_given_no)
P(sycophantic | flag)40%
flag rate22.5%
true rate10%
P(S | flag) = 0.9 × 0.1 / (0.9 × 0.1 + 0.15 × 0.9) = 0.09 / 0.225 = 0.40

Only 40%. The 135 false flags outnumber the 90 real ones. The flag rate is 22.5%, which overstates the true 10% by 12.5 percentage points. If you report "22.5% of answers are sycophantic", you're reporting your judge, not your model.

Q10 · random variables↺ day 5

Two coins, one shift

X = number of heads in 2 fair coins. Give the PMF, F(1), E[X] and Var(X). Then for Y = 3X − 2, find E[Y] and Var(Y).

PMF ¼, ½, ¼   F(1) = 0.75   E[X] = 1   Var(X) = ¼·1 + ½·0 + ¼·1 = 0.5
E[Y] = 3·1 − 2 = 1   Var(Y) = 3²·0.5 = 4.5  # shifting doesn't change spread; scaling multiplies it by a²

def tukey_fences(x, k=1.5):
    """Return (lower_fence, upper_fence) = (Q1 - k*IQR, Q3 + k*IQR)."""
    q1, q3 = percentile(x, 25), percentile(x, 75)
    spread = q3 - q1
    return q1 - k * spread, q3 + k * spread


def zscore_outliers(x, t=3.0):
    """Indices of values with |z| > t. Not robust: the outlier inflates the std
    it is measured with (masking). With n values, |z| can never exceed (n-1)/sqrt(n).
    """
    avg, sd = mean(x), std(x)
    if sd == 0:
        return []
    return [i for i, v in enumerate(x) if abs((v - avg) / sd) > t]

def pearson(x,y):
    x = np.array(x)
    y = np.array(y)
    x_std = x.std(ddof=1)
    y_std = y.std(ddof=1)
    if x_std == 0 or y_std == 0:
        raise ValueError("the standard deviation is zero")
    return (covariance(x,y))/(x_std * y_std)

def spearman(x,y):
    return pearson(rank(x),rank(y))

def bayes_posterior(prior,p_flag_given_yes,p_flag_given_no):
    p_opposite = 1- prior

    p_spam_flagged = prior * p_flag_given_yes
    p_notspam_flagged = p_opposite * p_flag_given_no
    all_flagged = p_spam_flagged + p_notspam_flagged

    return p_spam_flagged/all_flagged
