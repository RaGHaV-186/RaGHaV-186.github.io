Finding the Centre: Mean, Median & Mode

When someone asks for a "typical" number — a typical height, a typical salary, or a typical review score — there is no single right answer. We have three different instruments for finding the centre, and each one can be tricked in its own way.

Intuition Before Formulas

2. Three Ways to Say "Typical"

Before writing a single Greek letter, picture what each measure physically does to your data. Drag or click inside each diagram below to feel how they work.

1 · Mean

The Balance Point of a Seesaw

Imagine placing equal-weight blocks along a weightless plank. Every block pulls downward with torque proportional to its distance from the fulcrum. The mean is the exact spot where the seesaw balances flat.

Formula: mean(x) = (x₁ + x₂ + … + xₙ) / n
Sum of all values divided by count n. Because every xᵢ is inside the sum, one distant outlier pulls the balance point toward itself.
2 · Median

The Person in the Middle of a Queue

Line everyone up from shortest to tallest and walk inward from both ends one step at a time. The median only cares about who stands in the middle slot — not how tall the tallest person is.

Rule: Sort s; if n is odd → s[n // 2]; if even → (s[n//2 - 1] + s[n//2]) / 2
Half the data sits at or below the median, and half sits at or above it.
3 · Mode

The Most Common Value

Put identical items into stacks and look for the tallest stack. The mode is the only measure of centre that works for categories like words, colours, or programming languages.

Rule: All values x where count(x) == max(counts)
Requires no arithmetic — only equality checks and counting. Can return multiple winners if there is a tie.

Decision Rule

6. Choosing One: Which Centre Should You Use?

Whenever you meet a new dataset in machine learning — whether you are imputing missing values or summarising model latencies — follow this three-branch rule:

Categories → Mode

Use Mode for Categories

When values are labels, words, or discrete buckets where the most common item is what matters (e.g., most common predicted class in a voting classifier, or filling missing categorical features).

Skewed / Outliers → Median

Use Median for Skewed Data

When a few extreme numbers would distort the average — salaries, house prices, API tail latencies, or datasets with corrupted sensor spikes.

Roughly Symmetric → Mean

Use Mean for Symmetric Data

When distribution is roughly bell-shaped without wild outliers (like adult heights within a group or Gaussian noise), and you want every data point to contribute smoothly.

8. The Code Behind It

On the left is my Python implementation from my ml-from-scratch repository. On the right is the JavaScript port that powers every live calculation on this page. Notice how both versions handle even-length lists in median() and return all tied winners in mode().

stats.py — My own code Python (Mine) 
def mean(xs: list[float]) -> float:
    if len(xs) == 0:
        raise ValueError("mean() requires at least one value")
    return sum(xs) / len(xs)


def median(xs: list[float]) -> float:
    if len(xs) == 0:
        raise ValueError("median() requires at least one value")
    s = sorted(xs)
    n = len(s)
    mid = n // 2
    if n % 2 == 1:
        return s[mid]
    else:
        return (s[mid - 1] + s[mid]) / 2


def mode(xs: list[float]) -> list[float]:
    if len(xs) == 0:
        raise ValueError("mode() requires at least one value")
    counts = {}
    for num in xs:
        if num not in counts:
            counts[num] = 1
        else:
            counts[num] += 1

    highest = max(counts.values())
    return [num for num, c in counts.items() if c == highest]
stats.js — Written with AI help JavaScript Port 
function mean(xs) {
  if (xs.length === 0) {
    throw new Error("mean() requires at least one value");
  }
  const total = xs.reduce((acc, val) => acc + val, 0);
  return total / xs.length;
}


function median(xs) {
  if (xs.length === 0) {
    throw new Error("median() requires at least one value");
  }
  // Numeric comparator required: plain .sort() sorts as strings!
  const s = [...xs].sort((a, b) => a - b);
  const n = s.length;
  const mid = Math.floor(n / 2);
  if (n % 2 === 1) {
    return s[mid];
  } else {
    return (s[mid - 1] + s[mid]) / 2;
  }
}


function mode(xs) {
  if (xs.length === 0) {
    throw new Error("mode() requires at least one value");
  }
  const counts = new Map();
  for (const num of xs) {
    counts.set(num, (counts.get(num) || 0) + 1);
  }

  const highest = Math.max(...counts.values());
  const modes = [];
  for (const [num, c] of counts.entries()) {
    if (c === highest) {
      modes.push(num);
    }
  }
  return modes;
}
