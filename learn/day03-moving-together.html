Moving Together: Covariance, Correlation & Ranks

Days 1 and 2 described one variable at a time. Today's question is about two: when one goes up, does the other go up too? Five students, the hours they studied and their exam scores.

Predict first

Hours studied: 1, 2, 3, 4, 5. Exam scores: 2, 4, 5, 4, 5. Will the covariance come out positive, negative, or zero?

Formula: cov(x, y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n − 1)
Same n − 1 as the variance on Day 2, for the same reason: the distances are measured from the sample's own means. In fact var(x) = cov(x, x).

2. Covariance Is an Average of Signed Rectangles

Each product (xᵢ − x̄)(yᵢ − ȳ) is the area of a rectangle from the point to the crosshair of the means. Rectangles in the agreeing corners count as positive, the others as negative. Drag any point, and try the two buttons.

Fixing the Units Problem

3. Pearson r: Covariance on a Fixed Scale

The sign of the covariance tells you the direction, but its size depends on the units. Writing the scores in cents instead of euros makes it 100× bigger without changing anything about the relationship. So we divide by both standard deviations, which carry the same units, and they cancel.

Why It Can Never Leave [−1, +1]

4. Correlation Is the Cosine of an Angle

Write the centred values as two arrows: x − x̄ and y − ȳ, one direction per data point. The covariance mixes how much the arrows point the same way with how long they are. Dividing by the two stds removes the lengths, leaving only the angle between them. And the cosine of an angle can never go past +1 or −1: two arrows can't point "more the same way" than exactly the same way.

cos(angle) = r
Meaning

Arrows perfectly aligned means y − ȳ = c·(x − x̄) for every point, which is exactly the equation of a straight line. So "the arrows point the same way" and "the points lie on a straight line" are the same fact in two pictures.

A Trap

5. r = 0 Does Not Mean "Unrelated"

Here y is completely determined by x (y = x²), yet the covariance and r are exactly 0. The left half gives negative rectangles, the right half positive ones, and they cancel. r only detects straight-line patterns, so always plot your data.

Correlation ≠ Causation

6. Three Other Reasons Two Things Move Together

Confounder

A hidden third variable drives both

Ice-cream sales and drownings rise together because hot weather drives both. Cities with more firefighters have more fire damage because bigger cities and bigger fires bring more of both.

Reverse causation

The arrow points the other way

Students who get tutoring have lower grades, because low grades lead to tutoring. Cities with more police have more crime, because crime leads to hiring police.

Chance

Small samples invent patterns

Two completely unrelated variables can show a large r by luck, especially with few points. Try it below.

The two variables are generated completely independently, so the true correlation is 0.

Only a randomised experiment, where you assign x yourself, rules all three out. For my research on LLM evaluations: if German prompts come out more sycophantic, translation quality could be a confounder, which is why it has to be checked separately.

Order Instead of Values

7. Spearman: Pearson on the Ranks

Spearman throws away the actual numbers and keeps only their order, like a race podium that records who came 1st, 2nd and 3rd but not the margins. Then it runs ordinary Pearson on those ranks.

Actual values

Ranks

Ties: equal values share the average of the ranks they would occupy. For 5, 8, 8, 10 the two 8s would be 2nd and 3rd, so both get 2.5.
Shortcut when there are no ties: ρ = 1 − 6Σd² / (n(n² − 1)), where d is the difference between each pair of ranks.

When unsure, report both. If Spearman is much higher than Pearson, the relationship is monotonic but curved, or an outlier is distorting Pearson. LLM-judge scores and human ratings are ordinal 1–5 scales, which is why evaluation papers usually report Spearman's ρ.

From Scratch Implementation

9. The Code Behind It

I wrote covariance, pearson and spearman myself in my ml-from-scratch repository; rank was written with AI help. Note how pearson uses ddof=1 for the stds to match covariance, so the n − 1s cancel, and how rank averages the positions of tied values.

day03_correlation.pyPython (Mine, rank with AI help)
import numpy as np

def covariance(x,y,ddof=1):
    x = np.array(x)
    y = np.array(y)
    n = len(x)
    if len(x) != len(y):
        raise ValueError("Both arrays should be of equal length")
    if n-ddof <= 0:
        raise ValueError("n-ddof must be positive")

    dx = x -x.mean()
    dy = y - y.mean()

    pair_sum = (dx * dy).sum()

    return pair_sum/(n-ddof)

def pearson(x,y):
    x = np.array(x)
    y = np.array(y)
    x_std = x.std(ddof=1)
    y_std = y.std(ddof=1)
    if x_std == 0 or y_std == 0:
        raise ValueError("the standard deviation is zero")
    return (covariance(x,y))/(x_std * y_std)

def rank(x):
    x = np.array(x)
    s = np.sort(x)
    ranks = []
    for v in x:
        positions = np.where(s == v)[0]
        ranks.append(positions.mean() + 1)
    return np.array(ranks)

def spearman(x,y):
    return pearson(rank(x),rank(y))
JavaScript port (this page)JS (written with AI help)
function mean(x) {
  return x.reduce((a, b) => a + b, 0) / x.length;
}

function covariance(x, y, ddof = 1) {
  const n = x.length;
  if (n !== y.length) throw new Error("Both arrays should be of equal length");
  if (n - ddof <= 0) throw new Error("n-ddof must be positive");
  const mx = mean(x), my = mean(y);
  let pairSum = 0;
  for (let i = 0; i < n; i++) pairSum += (x[i] - mx) * (y[i] - my);
  return pairSum / (n - ddof);
}

function std(x) {
  return Math.sqrt(covariance(x, x));   // var(x) = cov(x, x)
}

function pearson(x, y) {
  const sx = std(x), sy = std(y);
  if (sx === 0 || sy === 0) throw new Error("the standard deviation is zero");
  return covariance(x, y) / (sx * sy);
}

function rank(x) {
  const s = [...x].sort((a, b) => a - b);   // numeric sort!
  return x.map(v => {
    const positions = [];
    s.forEach((w, i) => { if (w === v) positions.push(i); });
    return mean(positions) + 1;               // ties share the average
  });
}

function spearman(x, y) {
  return pearson(rank(x), rank(y));
}
