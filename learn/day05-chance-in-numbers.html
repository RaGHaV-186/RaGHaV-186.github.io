Chance in Numbers: Bayes, Random Variables & Expected Values

A sycophancy detector catches 90% of sycophantic answers. It flags an answer. How sure can you be that the answer is really sycophantic? Bayes' theorem flips "flag given sycophantic" into "sycophantic given flag", and it's just Day 4's shrink the room on a tree.

Predict first

2% of answers are sycophantic. The detector flags 90% of those, and wrongly flags 5% of honest answers. It flags an answer. The chance it's really sycophantic is about…

Flagged room (all ★)
Really "yes" in it
Posterior P(yes given flag)

Bayes: P(A given B) = P(B given A) × P(A) / P(B), with P(B) = P(B given A)·P(A) + P(B given not A)·P(not A)
In tree words: matching path ÷ all matching paths. Multiply along a path, add across paths. Prior P(A) = before the evidence; likelihood P(B given A) = the detector's catch rate; evidence P(B) = all flags; posterior P(A given B) = what we want. Counts out of 1000 and probabilities give the same answer, because the 1000 cancels.

The base-rate effect: same detector, different priors

When "yes" is rare, even a small false-alarm rate on the huge "no" group produces more false flags than real catches. So an eval that reports only "the judge catches 90%" hides how many of its flags are wrong: always report the base rate.

Turning Outcomes into Numbers

2. Random Variables, PMF and CDF

A random variable X is a rule that turns each outcome into a number, and the question decides which number. The same die can give "the face", "1 if even", or "€12 on a six". The recipe never changes: list the outcomes, write X under each, group equal X's, and divide by the total. That table is the PMF. Its running total is the CDF.

PMF: P(X = x), with E[X] as the balance point ▲ and E ± one std ↔

CDF: P(X ≤ x), a staircase that ends at 1

E[X]
Var(X)
std = √Var

There's no single "PMF formula". It's always (outcomes with that x) ÷ (all outcomes), and logic is the method. Formulas are counting shortcuts for when listing gets too long, like C(n, k) / 2ⁿ for heads in n fair flips. Careful with two dice: there are 6² = 36 outcomes, not 12, and a six is 1/6, not 50/50.

The Long-Run Average

4. Expected Value: Should You Play This Game?

E[X] = Σ x × P(X = x) is the Day 1 mean with the ÷ n moved inside: each value weighted by how often it happens. Roll a die; a six wins €12, anything else wins nothing. Play six times with each face once and you win €12, so €2 per game. If a game costs more than €2, you lose in the long run, and the simulation shows it.

E[winnings]€2
E[profit] = €2 − price
Games played
Your average profit

Rules: E[aX + b] = a·E[X] + b E[X + Y] = E[X] + E[Y] (always)
So the profit's expectation is just E[winnings] − price. Sanity-check every E[X]: for 2 coins at €4 per head you expect 1 head, so €4, and the sum 0·¼ + 4·½ + 8·¼ = 4 agrees.
Same Centre, Different Spread

5. Variance of a Random Variable

Two spinners, both with E[X] = 2: one always lands on 2, the other on 0 or 4. Variance measures the gap, exactly like Day 2, but each squared distance is weighted by its probability instead of divided by n. There's no n − 1 here: we know the whole distribution, so it isn't a sample.

Recipe: Var(X) = Σ (x − E[X])² × P(X = x): E first → distance of each value → square → × its own P → add.
Two easy slips: subtracting E from the probability instead of the value, and adding the P instead of multiplying by it. Rules: Var(X + b) = Var(X) (shifting moves the centre, not the spread), Var(aX) = a²·Var(X).
The Smallest Random Variable

6. Bernoulli: One Yes/No Try

X = 1 with probability p, X = 0 otherwise. A coin flip, one jailbreak attempt, one answer judged sycophantic or not. Every eval percentage (accuracy, refusal rate, attack success rate) is an average of Bernoullis, and p(1 − p) is how unpredictable one try is.

E[X] = p
Var = p(1 − p)
SE of a rate, N = 100

With p = 0.2 the recipe gives (0 − 0.2)²·0.8 + (1 − 0.2)²·0.2 = 0.032 + 0.128 = 0.16 = 0.2 × 0.8. That p(1 − p) is the one inside Day 4's standard error √(p(1 − p)/N). A 50% refusal rate is the hardest to pin down; a rate near 0 or 1 is easy. Add up n Bernoullis and you get the binomial: the number of successes.

def bayes_posterior(prior,p_flag_given_yes,p_flag_given_no):
    p_opposite = 1- prior

    p_spam_flagged = prior * p_flag_given_yes
    p_notspam_flagged = p_opposite * p_flag_given_no
    all_flagged = p_spam_flagged + p_notspam_flagged

    return p_spam_flagged/all_flagged

def cdf(probs):
    running_sum = 0
    res_cdf = []
    for num in probs:
        running_sum = running_sum + num
        res_cdf.append(running_sum)

    return res_cdf

def expectation(values,probs):
    exp = 0
    for value,prob in zip(values,probs):
        exp += value * prob

    return exp

def variance(values,probs):
    exp = expectation(values,probs)
    var = 0
    for value,prob in zip(values,probs):
        var += (value-exp)**2 * prob

    return var

function bayesPosterior(prior, pFlagGivenYes, pFlagGivenNo) {
  const pNo = 1 - prior;
  const yesAndFlag = prior * pFlagGivenYes;   // matching path
  const noAndFlag = pNo * pFlagGivenNo;       // false alarms
  const allFlagged = yesAndFlag + noAndFlag;  // add across
  return yesAndFlag / allFlagged;
}

function cdf(probs) {
  let runningSum = 0;
  const res = [];
  for (const p of probs) {
    runningSum += p;
    res.push(runningSum);    // push, don't assign its result
  }
  return res;
}

function expectation(values, probs) {
  let e = 0;
  values.forEach((x, i) => { e += x * probs[i]; });
  return e;
}

function variance(values, probs) {
  const e = expectation(values, probs);
  let v = 0;
  values.forEach((x, i) => { v += (x - e) ** 2 * probs[i]; });
  return v;
}
