Measuring Spread: Same Average, Very Different Days

Intuition Before Formulas

2. The Mean Is a Point. The Std Is a Width.

Mean, median and mode all answer where. The standard deviation answers how wide: how far, typically, a value lands from the mean. Drag the slider: the crowd's centre never moves, only its width.

Why not just average the signed distances? Because they always add up to exactly 0: the mean is the balance point. Squaring is how we stop the left and right sides cancelling.
The Question Everyone Asks

3. Why Divide by n − 1 and Not n?

We usually only have a small sample, and we measure distances from the sample's own mean. That mean sits right in the middle of the sample, so the distances come out a little too small. It's like throwing three darts and then drawing the bullseye where they landed: of course they look close to the centre.

Predict first

A fair die has a true variance of 35/12 ≈ 2.92. We roll it a few times, compute the variance both ways, and repeat thousands of times. Which average lands on the true value?

Why exactly − 1? On average, the sum of squared distances from the sample mean equals (n − 1) × the true variance, not n × it.
Once the sample mean is known, the distances must add up to zero, so only n − 1 of them are free; the last one is forced and carries no new information. Dividing by n − 1 counts only the free pieces. The effect is big for small samples (n = 2: dividing by n gives half the truth) and fades as n grows (n = 1,000: 0.1%).
The Std as a Ruler

4. z-Scores: How Many Std Steps Away?

Mark a ruler starting at the mean, with one mark every standard deviation. A z-score counts the steps: z = (x − mean) / std. Every class gets its own ruler, which is what makes different scales comparable. Your maths exam (class mean 70, std 5) and German exam (class mean 85, std 10):

Maths: class mean 70, std 5 ·

German: class mean 85, std 10 ·

Both on one shared ruler (z)

Memory hook: mean = where you stand · std = the length of one step · z = how many steps away you are.
For bell-shaped data, landing more than 3 steps out is rare (about 0.3% of values), so "|z| > 3" is a common outlier rule. Section 6 shows when that rule quietly breaks.
Ranks Instead of Distances

5. Percentiles: Walking Along the Sorted Data

The p-th percentile is the value with p% of the data below it. Sort the data, number the positions from 0, and compute h = (n − 1) × q. If h lands between two positions, walk that fraction of the way from one value to the next.

Q1
Q3
IQR = Q3 − Q1

The IQR is the width of the middle half of the data. Like the median, it never looks at the extremes, so a single wild value can't inflate it. That makes it the robust cousin of the std.

Two Detectors, One Gets Fooled

6. Outliers: Tukey's Fences vs z-Scores

Tukey's fences flag anything beyond Q1 − 1.5·IQR or Q3 + 1.5·IQR. The z rule flags anything more than 3 std from the mean. Drag the suspicious value further and further out, and watch which detector notices.

Predict first

Highest z possible with n values

Why the z rule gets fooled (masking): the suspicious value is part of the data used to compute the mean and std. It drags the mean toward itself and stretches the std, so the ruler grows as fast as the point moves away.
Worked case: five values at 0 and one at 6. Mean = 1, distances 1, 1, 1, 1, 1 and 5, squares sum to 30, sample variance 30 / 5 = 6, std = √6. So z = 5 / √6 ≈ 2.04, and making the value 10× bigger makes the distance and the std 10× bigger, so z stays 2.04. In general the ceiling is (n − 1) / √n, which only passes 3 once n ≥ 11. Quartiles ignore the extremes, so Tukey's fences can't be stretched this way.
Matching the Tool to the Data

7. Which Spread Should You Report?

Mean ± std

Roughly symmetric data

Heights, exam scores in a big class, measurement errors. Uses every value, and the maths behind most of ML (z-scores, standardisation, the normal distribution) is built on it.

Median & IQR

Skewed data or outliers

House prices, salaries, response times. A few mansions drag the mean and the std up; the median and IQR only look at the middle of the data.

Small samples

Fewer than ~11 values

Use the n − 1 version of the variance, and find outliers with Tukey's fences, never with "|z| > 3", which mathematically can't fire.

When Correct Maths Gives Wrong Answers

8. Computing It Safely: The Shortcut That Breaks, and Welford

On paper, variance = mean(x²) − mean(x)². In a computer, that subtracts two huge, nearly equal numbers, and the small difference you want gets lost in rounding. This is called catastrophic cancellation. Shift the data [4, 7, 13, 16] (true variance 22.5) further and further from zero:

Shortcut mean(x²) − mean(x)²
Two-pass
Welford

Welford: updating as each value arrives

The two-pass method needs all the data twice (once for the mean, once for the distances). Welford's algorithm keeps just three numbers and updates them as each value streams in, like a fitness tracker updating your average heart rate beat by beat. Feed it Bus B's 1, 3, 5, 7:

New xndelta = x − old meannew meanM2 += delta × (x − new mean)M2
Start: n = 0, mean = 0, M2 = 0

M2 is the running sum of squared distances. At the end, variance = M2 / (n − 1).

def variance(x, ddof=0):
    n = len(x)
    if n - ddof <= 0:
        raise ValueError(f"Need len(x) - ddof > 0, got len(x)={n}, ddof={ddof}.")
    avg = mean(x)
    sum_of_squares = 0
    for num in x:
        sum_of_squares += (num - avg) ** 2
    return sum_of_squares / (n - ddof)


def std(x, ddof=0):
    return math.sqrt(variance(x, ddof))


def welford(x, ddof=0):
    k, running_mean, m2 = 0, 0.0, 0.0
    for value in x:
        k += 1                                  # 1. count it
        delta = value - running_mean            # 2. gap to the OLD mean
        running_mean += delta / k               # 3. nudge the mean
        m2 += delta * (value - running_mean)    # 4. old gap x NEW gap
    if k - ddof <= 0:
        raise ValueError(f"Need count - ddof > 0, got count={k}, ddof={ddof}.")
    return m2 / (k - ddof)


def percentile(x, q):
    if len(x) == 0:
        raise ValueError("Need at least one value.")
    if not 0 <= q <= 100:
        raise ValueError(f"q must be in [0, 100], got {q}.")
    s = sorted(x)
    h = (len(s) - 1) * q / 100
    lower = math.floor(h)
    upper = min(lower + 1, len(s) - 1)
    fraction = h - lower
    return s[lower] + fraction * (s[upper] - s[lower])


def iqr(x):
    return percentile(x, 75) - percentile(x, 25)


def tukey_fences(x, k=1.5):
    q1, q3 = percentile(x, 25), percentile(x, 75)
    spread = q3 - q1
    return q1 - k * spread, q3 + k * spread


def tukey_outliers(x, k=1.5):
    low, high = tukey_fences(x, k)
    return [i for i, v in enumerate(x) if v < low or v > high]


def zscore_outliers(x, t=3.0):
    avg, sd = mean(x), std(x, ddof=1)
    if sd == 0:
        return []
    return [i for i, v in enumerate(x) if abs((v - avg) / sd) > t]

function variance(x, ddof = 0) {
  const n = x.length;
  if (n - ddof <= 0) throw new Error("Need len(x) - ddof > 0");
  const avg = mean(x);
  let sumOfSquares = 0;
  for (const num of x) sumOfSquares += (num - avg) ** 2;
  return sumOfSquares / (n - ddof);
}

function std(x, ddof = 0) {
  return Math.sqrt(variance(x, ddof));
}

function welford(x, ddof = 0) {
  let k = 0, runningMean = 0, m2 = 0;
  for (const value of x) {
    k += 1;
    const delta = value - runningMean;   // gap to the OLD mean
    runningMean += delta / k;            // nudge the mean
    m2 += delta * (value - runningMean); // old gap x NEW gap
  }
  if (k - ddof <= 0) throw new Error("Need count - ddof > 0");
  return m2 / (k - ddof);
}

function percentile(x, q) {
  if (x.length === 0) throw new Error("Need at least one value.");
  if (q < 0 || q > 100) throw new Error("q must be in [0, 100]");
  const s = [...x].sort((a, b) => a - b);  // numeric sort!
  const h = (s.length - 1) * q / 100;
  const lower = Math.floor(h);
  const upper = Math.min(lower + 1, s.length - 1);
  const fraction = h - lower;
  return s[lower] + fraction * (s[upper] - s[lower]);
}

function iqr(x) {
  return percentile(x, 75) - percentile(x, 25);
}

function tukeyFences(x, k = 1.5) {
  const q1 = percentile(x, 25), q3 = percentile(x, 75);
  const spread = q3 - q1;
  return [q1 - k * spread, q3 + k * spread];
}

function tukeyOutliers(x, k = 1.5) {
  const [low, high] = tukeyFences(x, k);
  return x.flatMap((v, i) => (v < low || v > high ? [i] : []));
}

function zscoreOutliers(x, t = 3) {
  const avg = mean(x), sd = std(x, 1);
  if (sd === 0) return [];
  return x.flatMap((v, i) => (Math.abs((v - avg) / sd) > t ? [i] : []));
}
