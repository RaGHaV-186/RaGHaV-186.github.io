# 01 · bernoulli

One customer: yes or no

Does the next customer buy a croissant? The outcome is 1 (yes) with probability p and 0 (no) with probability 1 − p. That's the whole distribution.

P(1) = p   P(0) = 1 − p  │  E[X] = 0·(1 − p) + 1·p = p

Variance is trickier. Because X is 0 or 1, X² = X (0² = 0 and 1² = 1). So E[X²] = p, and:

Var(X) = E[X²] − (E[X])² = p − p² = p(1 − p) = 0.25 − (p − 0.5)²
predict first

Which customer is hardest to guess: one who buys 10% of the time, 50%, or 90%?

p = 0.5. At 0.1 or 0.9 you'd guess right most of the time; at 0.5 you're flipping a coin. Variance measures exactly that, and it peaks at 0.25 when p = 0.5. Drag the slider and watch why.

A spam filter that's right 95% of the time is a Bernoulli with p = 0.95. Its variance is 0.95 × 0.05 = 0.0475, much smaller than a coin's 0.25, because it's very predictable.
# 02 · binomial

Twenty customers: how many say yes?

Add up n independent Bernoullis and you get a Binomial. To get exactly k yeses: count the orders they could come in, then multiply by the probability of any one order.

P(k) = C(n, k) · pk (1 − p)n−k  ← orders × one order
E = n·p   Var = n·p(1 − p)  # means and variances of independent pieces add

Bakery: 20 customers at p = 0.4 gives a mean of 8 croissant buyers and a variance of 4.8. Now an ML version: you test a model on 20 prompts and it truly fails 30% of the time (p = 0.3). The mean is 6 failures with a std of about 2.

# 03 · poisson + exponential

One timeline, two questions

Now we only know a rate: 12 customers an hour, or 4 spam emails a day. No fixed n. Two questions live on the same timeline:

  • Poisson counts: how many arrive in a window?
  • Exponential times: how long until the next one?
Poisson: P(k) = λk e−λ / k!   E = Var = λ
Exponential: P(wait > t) = e−λt   f(t) = λe−λt   E = 1/λ
Rain on a window: drops per minute is Poisson; seconds until the next drop is Exponential. Same rain, two questions.

The link: "zero emails in the next t" is Poisson with k = 0, which is e−λt, exactly the Exponential's "wait longer than t".

For a real Poisson, variance ≈ mean. Turn on campaigns (same average rate, but bursty) and the variance shoots past the mean. That's overdispersion: my "mean 4, variance 20" inbox wasn't Poisson, it was bursts.

With λ = 4/day: P(no spam all day) = e−4 ≈ 0.018, so a spam-free day comes about once every 55 days. The mean gap is ¼ day = 6 hours.

# 04 · memoryless

The bus is never "due"

After 12 quiet hours, surely spam is "due"? No. For the Exponential, how long you've already waited changes nothing. Drag the slider: cut the curve at any point, rescale what's left, and it is the same curve again.

P(wait > s + t | wait > s) = e−λ(s+t) / e−λs = e−λt # s cancels

# 05 · uniform + sampling

A dart on a ruler

If every point in [a, b] is equally likely, probability is just slice width ÷ total width. A timetabled bus every 20 minutes: wait ~ Uniform(0, 20), mean 10, P(wait < 5) = 5/20 = 25%.

P(slice) = width / (b − a)   E = (a + b)/2   Var = (b − a)²/12

Here's the trick that makes it powerful: throw a dart U on a 1-metre ruler and paint the first p metres "FLAG". Then U < p is a Bernoulli(p). That's exactly how my sample_bernoulli works.

Two buses, same 3 per hour: timetabled every 20 minutes gives an average wait of 10 minutes. Random arrivals give an average wait of 20 minutes, twice as long. The Uniform's "not too long" guarantee is gone.
# 06 · normal

Many small things add up to a bell

Roll one die: flat. Two dice: a triangle. Ten dice: a bell. Highs and lows cancel out, so totals near the middle can happen in millions of ways and extreme totals in almost none.

f(x) = 1/(σ√(2π)) · e−(x−μ)²/(2σ²)   z = (x − μ)/σ

Every Normal is the same curve, just shifted by μ and stretched by σ. So we measure in z-scores: how many σ away from the mean. 68% of values lie within 1σ, 95% within 2σ, 99.7% within 3σ.

ML version: answer lengths ~ N(200, 30 tokens). 95% fall in 140–260 tokens. A 320-token answer is z = (320 − 200)/30 = 4, rarer than 1 in 15,000. Worth a look in the logs.

# 07 · decision rule

Hear the question, pick the shape

a time until something → Exponential
a count with known n → Bernoulli (n = 1) / Binomial
a count with only a rate → Poisson
equally likely in a range → Uniform
a sum of many small effects → Normal
# 08 · code

The code behind every simulation

Every simulation above runs a JavaScript port of these functions. They're written from scratch with only math and NumPy's random generator, and checked against scipy.stats.

p0_math/b02_distributions/day08_distributions.pywritten by me
import math

import numpy as np


def bernoulli_pmf(k, p):
    if p > 1 or p < 0:
        raise ValueError

    if k == 1:
        return p
    elif k == 0:
        return 1 - p
    else:
        return 0


def binomial_pmf(k, n, p):
    if p > 1 or p < 0:
        raise ValueError
    if k < 0 or k > n:
        return 0

    return math.comb(n, k) * (p**k) * ((1 - p) ** (n - k))


def poisson_pmf(k, lam):
    if lam <= 0:
        raise ValueError
    if k < 0:
        return 0

    return (lam**k) * (math.exp(-lam)) / math.factorial(k)


def exponential_pdf(t, lam):
    if lam <= 0:
        raise ValueError

    if t < 0:
        return 0

    return lam * math.exp(-lam * t)


def exponential_cdf(t, lam):
    if lam <= 0:
        raise ValueError

    if t < 0:
        return 0

    return 1 - math.exp(-lam * t)


def uniform_pdf(x, a, b):
    if b <= a:
        raise ValueError
    if x >= a and x <= b:
        return 1 / (b - a)
    else:
        return 0


def normal_pdf(x, mu, sigma):
    if sigma <= 0:
        raise ValueError

    return math.exp(-((x - mu) ** 2) / (2 * sigma**2)) / (
        sigma * math.sqrt(2 * math.pi)
    )


def sample_bernoulli(p, size, rng):
    if p > 1 or p < 0:
        raise ValueError

    u = rng.random(size)
    return (u < p).astype(int)


def sample_exponential(lam, size, rng):
    if lam <= 0:
        raise ValueError

    u = rng.random(size)
    return -np.log(1 - u) / lam
